# SmartBudgetManagger
3. README
3.1 Project Overview
SmartBudget Manager is an Excel workbook that helps users organize and monitor their personal finances. It provides a simple way to record income and expenses and review monthly financial information.
3.2 Main Features
·       Recording income and expenses.
·       Organizing transactions by category.
·       Calculating financial totals and monthly balance.
·       Displaying charts on the Dashboard.
·       Showing budget warnings when the feature is available and configured.
3.3 Workbook Structure
Dashboard: Displays financial summaries, the monthly balance, and charts.
Transactions: Contains the records of income and expenses.
Categories: Lists the expense categories used to organize transactions.
3.4 System Requirements
A computer with Microsoft Excel or a compatible spreadsheet application is required.
3.5 Getting Started
1.     Open the SmartBudget_Manager.xlsx file.
2.     Read the column headings in the Transactions worksheet.
3.     Enter income and expense records in the appropriate fields.
4.     Select the correct category for each transaction.
5.     Open the Dashboard to review the financial summary.
6.     Save your changes using Ctrl + S.
3.6 Important Notes
Enter amounts and dates carefully. Do not overwrite cells containing formulas. Check the Dashboard after updating transactions and keep a backup copy of the workbook.
